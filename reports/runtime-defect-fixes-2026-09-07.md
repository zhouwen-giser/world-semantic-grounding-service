## 实现

- Compose 向 API 传入独立的新协议消费者白名单、可选主数据域和原文保留期限；向 Worker 传入清理周期和批量大小。空主域表示未指定，不放宽非空值或身份授权检查。
- Worker 启动时及随后每 60 秒串行清理，默认每批 100 条。事务锁定已过期的终态任务及请求，清空请求密文并删除检查点，也处理只有检查点残留的历史数据。活动任务保持原截止时间；结果、哈希、幂等重放与审计事件保留。分析追问有效期不延长。
- Worker 对已知数据库连接、超时和事务冲突采用 500 毫秒至 30 秒的退避。解密、请求或存储身份校验失败按租约和代际隔离为单任务失败。提交确认丢失不会触发覆盖失败写入；未知运行异常停止领任务并收尾其他任务。
- 专用 LISTEN 连接故障不会成为未处理异常；连接丢失后继续通过租约心跳检查取消状态，重建 Worker 后恢复推送通知。
- 非法或空 JSON 返回 400，未支持媒体类型返回 415，超限请求保留 413，均不可重试；未知内部错误继续使用脱敏 500 信封。

配置说明见 [运行手册](../docs/runbook.md)；保留期限和追问行为见 [上下文与原文保留](../docs/context-and-prior-grounding.md)。
