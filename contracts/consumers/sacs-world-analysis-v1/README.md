# World Analysis Consumer Candidate

Run `node verify.mjs` with Node.js 22 or newer. No installation or network is required.

The `public/` directory contains the byte-identical frozen schemas, TypeScript types, validator, OpenAPI, limits, semantics and complete examples. Read `public/README.md` and `public/SEMANTICS.md` for negotiation, selection, cancellation and action non-authorization. `node_modules/` contains only the explicitly listed validator runtime dependencies and licenses.

This is an offline contract candidate, not evidence of live SACS, Gateway, database or provider integration. W06 and final release gates remain separate.
